# CraftBridgeJP

CraftBridgeJP は、DiscordSRV が Discord に送信する進捗通知の進捗名と死亡ログを、Minecraft 公式の日本語翻訳データを使って日本語化する Paper プラグインです。

## 主な機能

* **進捗通知の日本語化**：Discordに送信される進捗名を日本語で表示します。
* **死亡ログの日本語化**：Discordに送信される死亡メッセージを日本語で表示します。

## 導入方法

1. 配布ページから `CraftBridgeJP` の JAR ファイルをダウンロードします。
2. サーバーの `plugins` フォルダに配置します。
3. サーバーを再起動します。
4. 起動ログを確認し、プラグインが正常に読み込まれたことを確認します。
